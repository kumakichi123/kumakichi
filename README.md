# kumakichi

C.-R. Hu (1994) の論文を読み解き、発表を準備するための学習プロジェクト。

## 対象論文
C.-R. Hu, "Midgap surface states as a novel signature for d-wave superconductivity,"
Phys. Rev. Lett. 72, 1526–1529 (1994). DOI: https://doi.org/10.1103/PhysRevLett.72.1526

## ゴール
1. 論文の模型・導出・物理的意味・実験的示唆を理解する。
2. 理解した後に、物性・光分野の学生と教員向けに 20 分程度の論文発表を準備する。

## 構成
- `CLAUDE.md`：家庭教師「くまきち」の進め方（Claude 向けの指示）
- `notes/progress.md`：学習の進捗と、未解決の疑問
